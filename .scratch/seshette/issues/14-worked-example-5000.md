# 14: Worked example: 5,000 arXiv abstracts

**What to build:** The final committed worked example: `/datamap` run on a fixed-seed sample of 5,000 rows of `lmcinnes/arxiv_ml`. It commits a README walkthrough (the exact `/datamap` request, what came out, how long each stage took, ingest counts, and the noise share at each cluster layer), the code the agent generated (one file per scribe, labeled as generated by Seshette), the datamap HTML, and every table exported as Parquet. The datamap database itself is not committed, because Iceberg records absolute paths; the walkthrough has one step that rebuilds a local datamap database from the Parquet files.
